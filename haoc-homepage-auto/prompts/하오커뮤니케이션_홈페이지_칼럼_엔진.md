이 글이 그 질문의 '답'이 되게 쓴다. '제작 순서/방법' 같은 절차 주제는 버린다.

## [자동화 변경 내역] (수동판 → 자동판, 사용자 확인용)

1. **[제목]/[주제]/[글 유형] 입력칸 삭제** → 프로그램이 질문 CSV(정부지원사업/디자인/웹/스튜디오/마케팅)에서 오늘 슬롯 주제의 다음 미사용 질문을 골라 타겟 질문·주제·글 유형을 자동 주입. 제목은 AI가 자가 생성.
2. **[글 유형] 자동 결정**: 디자인·스튜디오=포트폴리오(참고 사진 + 대표이미지 1장), 웹·마케팅=정보글, 정부지원사업=질문에 산출물 단어가 있으면 포트폴리오.
3. **사진**: 사용자가 보내던 사진 → 프로그램이 하오디자인·하오스튜디오 Drive에서 미사용 프로젝트 사진을 골라 참고용으로 주입(Claude가 열어보고 글로 묘사). 본문에는 이미지가 들어가지 않고, 프로그램이 그 사진 1장을 대표이미지로 관리자 폼에 업로드한다.
4. **FAQ**: '하커 노출체크' 시트를 직접 열던 것 → 프로그램이 같은 주제 블록의 질문 후보를 주입.
5. **[날짜] 필드 삭제** → 프로그램이 게시일(오늘, 2026.09.14 형식)을 폼에 넣는다.
6. **출력**: .txt 파일 저장·전달 → json 블록(제목·요약) + text 블록(본문). 프로그램이 검증(태그·링크·이모지·구조·분량)·저장(.txt)·채점·게시(관리자 폼 자동 입력).
7. **유지한 것**: 브랜드·서비스·정부사업 매칭·콘텐츠 방향·수치 규칙·원고 구성(핵심 요약→인사→섹션 4→FAQ 5→신뢰→마무리)·순수 텍스트 규칙·이모지 금지·자가 채점 기준.

8. **썸네일 경로/URL(2026-09-18 운영자 지시)**: json 블록에 slug(영문 제목) 추가. 게시 도구가 파일 업로드 전에 #pImgUrl 칸에 "영문제목(소문자·공백없음).haoc.co.kr"을 먼저 입력한 뒤 썸네일 파일을 고른다.
