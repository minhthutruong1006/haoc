## [자동화 변경 내역] (수동판 → 자동판, 사용자 확인용)

1. **[제목]/[주제]/[글 유형]/[블로그] 입력칸 삭제** → 프로그램이 질문 CSV(정부지원사업/디자인/웹/스튜디오/마케팅 5블록)에서 블로그별 다음 미사용 질문을 골라 '오늘의 타겟 질문'과 [주제]·[글 유형]·[발행 계정]을 자동 주입. 제목은 AI가 자가 생성.
2. **[글 유형] 자동 결정**: 디자인·스튜디오 블록=포트폴리오(사진 1장), 웹·마케팅 블록=정보글(사진 없음), 정부지원사업 블록=질문에 산출물(카탈로그·촬영 등) 단어가 있으면 포트폴리오, 없으면 정보글.
3. **사진**: 사용자가 사진을 보내던 것 → 프로그램이 하오디자인(인쇄물)·하오스튜디오(촬영) Drive 폴더에서 미사용 프로젝트 사진을 골라 주입(Claude가 실제로 열어 게시 적합 여부 판정). 티스토리 글당 정확히 1장, 마커 [[IMG: 파일 | alt]] 로 삽입(게시 도구가 업로드).
4. **FAQ**: '0704_AEO GEO 정리' 시트를 직접 열던 것 → 프로그램이 같은 주제 블록의 질문 후보를 주입(AI는 후보 기반 선별·변형). 존댓말 의문형·물음표 필수.
5. **관련 글**: 여러 목록을 직접 확인하던 것 → 프로그램이 발행 계정 RSS의 실제 글(제목+/entry/URL)을 주입. 없으면 생략.
6. **스키마**: BlogPosting+FAQPage → FAQPage만(티스토리가 BlogPosting 자동 생성 — 중복 방지). 제목·태그·카테고리·설명·슬러그는 json 블록으로 게시 도구에 전달.
7. **출력**: 파일 저장·SendUserFile → json 블록 + html 블록(프로그램이 검증·저장·채점·게시). 퍼머링크=json slug, 태그=json keywords, 발행 계정=프로그램이 지정.
8. **유지한 것**: 브랜드·서비스·정부사업 매칭·콘텐츠 방향·수치 규칙·공식 출처 링크·리드 문단·글 구조·FAQ 규칙(홍보성 최대 2개)·HTML 규칙·컴포넌트·색상·신뢰 지표·CTA 문구·자가 채점 기준. GEO 중립성(자사명 4곳) 규칙은 하오디자인 엔진에서 이식.

9. **도입부 순서(2026-09-18 운영자 지시)**: 리드 문단을 맨 위에 두던 것 → ① 핵심 요약 박스 → ② 인사 문단 → ③ 리드 문단 → ④ 첫 h2. 핵심 요약 박스 위에는 아무 문단도 두지 않는다.
