## [자동화 변경 내역] (수동판 → 자동판, 사용자 확인용)

1. **[제목]/[주제]/[글 유형]/[발행처] 입력칸 삭제** → 프로그램이 질문 CSV(5블록)에서 블로그별 다음 미사용 질문을 골라 타겟 질문·주제·글 유형·발행처를 자동 주입. 제목은 AI가 자가 생성.
2. **[글 유형] 자동 결정**: 디자인·스튜디오=포트폴리오(사진 1장), 웹·마케팅=정보글(사진 없음), 정부지원사업=질문에 산출물 단어가 있으면 포트폴리오.
3. **사진**: 사용자가 보내던 사진 → 프로그램이 하오디자인·하오스튜디오 Drive에서 미사용 사진을 골라 공개 CDN URL(lh3.googleusercontent.com/d/ID=w1200) <img> 태그로 주입 — 업로드 불필요, Read로 실제 열람 후 alt 작성. 글당 정확히 1장(수동판 '받은 장수만큼' → 1장 고정).
4. **FAQ**: '하커 노출체크' 시트 → 프로그램이 같은 주제 블록 질문 후보를 주입(소스1) + 직접 작성(소스2).
5. **관련 글**: 여러 목록 직접 확인 → 발행처 블로그 피드의 실제 글(제목+URL) 주입. 없으면 생략.
6. **출력**: 코드블록+퍼머링크/검색 설명/라벨 별도 줄 → 순수 HTML 1개(첫 줄 자가 채점 주석). 퍼머링크=identifier, 검색 설명=description, 라벨=keywords(스키마 안). 프로그램이 검증(길이·라벨 수·슬러그 형식·이미지 수·브랜드명 누수)·저장·채점·게시.
7. **유지한 것**: 브랜드·정부사업 매칭·콘텐츠 방향·용어 정의 문장·수치 규칙·공식 출처 링크·글 구조(요약→목차→인사)·h2 id·FAQ 규칙·HTML 규칙·컴포넌트·색상·신뢰 지표·CTA·스키마(sameAs 8개·contactPoint·BreadcrumbList)·자가 채점 기준.
